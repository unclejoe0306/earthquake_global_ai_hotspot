## 專案來由

地震發生具有複雜的時間群聚與空間分布。不同構造帶的地震發生率也不相同，因此，即使一個模型涵蓋了許多強震，仍必須進一步檢查：這是訊號提供了額外資訊，還是長時間、大範圍警戒本來就容易涵蓋地震？

本研究由周裕清醫師發起，自2026年7月12日起持續累積每日日報，嘗試從地震目錄的近期變化，研究碎形與相關統計指標是否具有可重現的辨識價值。專案重視保存每日資料截點、觀察窗與結果，讓命中與未命中都能被追蹤，而非只展示成功案例。

研究採取逐步驗證方式：先建立大區域訊號與固定7日觀察窗，再平行比較不同觸發政策、隨機對照、警戒負擔與活動率基準；中尺度熱點則作為獨立研究，檢驗縮小地理範圍後能否保留事件覆蓋。

**公開研究結果不等於已證明能可靠預測地震。** 各種候選方法是否優於基準，須接受公平對照、統計不確定性與真正前瞻資料的檢驗。

## 網頁使用方法

### 1. 開啟網站，先看資料時間

可從本儲存庫的GitHub Pages網址，或[正式網站](https://global-seismic-fractal-analysis-dailyreport.unclejoe0306.chatgpt.site/)進入。

閱讀前先確認頁面上的日報日期、資料截點、USGS資料產生時間與目錄筆數，並查看是否標示備援、補算或離線資料。頁面載入時間、資料截點與地震發生時間是不同概念。

若畫面似乎未更新，電腦可按 `Ctrl + F5` 強制重新整理；手機可重新整理頁面，並再次核對頁面日期。

### 2. 今日熱點

首頁提供當日訊號總覽、重點變化、15區地理疊圖與新增納入的命中紀錄。

| 顯示內容 | 閱讀方式 |
| --- | --- |
| 高度警戒 | 指標異常觸發數達既定門檻的模型狀態，不是官方災害警報。 |
| SYNLOCK | 模型定義的同步鎖定狀態，不是直接量測到斷層應力閉鎖。 |
| SYNRELEASE | 模型定義的同步釋放狀態，不代表已證明無震滑移，也不是安全解除訊息。 |
| 紅框／黃框 | 原15區疊圖分別表示高度警戒與SYNLOCK；同區可同時顯示。 |
| 橘紅命中點 | 本次日報新增納入的匹配事件，實際發震日期須閱讀詳情。 |

點開命中卡，可查看USGS事件連結、發震時間、座標、深度、匹配觀察窗與領先時間。**「本日最新命中」可能包含延遲納入或修訂後才符合條件的舊發震事件，不等於當天新發生的地震數。**

### 3. 強震統計分析

查看整體與各分區的觀察窗、PPV、事件覆蓋、領先時間及歷史趨勢；詳細表格可點選展開。

請先辨認統計使用的是哪一組訊號、哪個觀測期間及哪種分母。固定開窗、每日訊號樣本、每日有效窗樣本與中尺度研究，不能直接混合比較。

### 4. 碎形分析圖

各區提供Z Thread與Δ Thread／Slope7等非WebGL圖表。依圖例觀察各指標變化，點圖可放大查看；歷史圖應以其對應日期與資料截點解讀。

Z-score警戒線是統計門檻；Δ／斜率圖具有不同意義，不能把它當成同一種Z-score圖。

### 5. 中尺度AI熱點預警研究

此子頁探索在非全球觀察區域內，以近期地震活動與背景資料建立較小範圍的活動熱點。現行研究展示方法包含近期30日M≥3.5、130日背景、1°網格與空間平滑，以及區域面積預算；實際設定與版本以子頁說明為準。

「AI熱點」是研究展示名稱，**熱度不是已校準的發震機率，也不表示具備精確定位強震的能力**。縮小地理範圍可降低面積×時間警戒負擔，但原168小時觀察窗不會因此自動縮短。

圖中父窗命中以紅色圓點、中尺度命中以黃色星號區分；高度警戒、SYNLOCK、SYNRELEASE分別以紅、黃、藍框表示。請依圖例、開窗截點與更新截點判讀。

中尺度結果獨立於原15區統計；回溯重建與真正前瞻紀錄分開。若顯示 `N/A`，代表缺乏合適分母或尚無成熟樣本，不能解讀為0%或100%。

### 6. 平行三策略前瞻研究

在現行政策之外，平行比較三項候選政策：

| 政策 | 觸發條件 |
| --- | --- |
| BASE：現行政策 | 高度門檻≥3，或SYNLOCK。 |
| H4L：候選一 | 高度門檻≥4，或SYNLOCK。 |
| H4LR：候選二 | 高度門檻≥4，或SYNLOCK，或SYNRELEASE。 |
| LR：候選三 | SYNLOCK，或SYNRELEASE。 |

門檻≥3／≥4指模型異常指標的觸發數，不是地震規模。候選政策納入SYNRELEASE，並不改變正式政策的原始定義。

比較內容包含成熟窗PPV、事件覆蓋、有效警戒時間／時空占比、隨機觸發、保留群聚的時間移位對照、同負擔活動率基準及Molchan型評估。目標是檢查誰能以較少警戒負擔捕捉較多事件，而不是只選最高的單一百分比。

pyCSEP相關L／N／S檢驗只適用於相應的機率模型評估層，不會自動替二元觀察窗產生機率，也不代表CSEP官方認證。研究展示同步不會自動替換正式模型。

### 7. 歷史日報與研究歷史

從歷史入口選擇日期，可查看對應日報、統計與圖集。研究子頁也保留其自身歷史。

不同子頁可能具有不同的最新完成日期；請勿把舊研究圖當成今日新預報。補算、歷史補繪與資料缺報應保留來源說明，不以新日期包裝舊結果。

## 核心方法與統計定義

正式日報使用USGS全球M≥3.5目錄、150日資料範圍、130日背景與3日／7日雙模型，分析b-value、Dt、Δα、D₀、H等指標的Z-score。各區依原始地理filter計算；|Z|>1.5用於異常觸發統計，高度警戒門檻為觸發數至少3。SYNLOCK／SYNRELEASE另依既定同步指標判定，不能只由單一Z值推定。

15區包括全球參考區、原始地理分區、組合分區與殘差補集區，彼此可能重疊。第15區「南北極圈+中洋脊」涵蓋原始地理filter聯集以外的區域，並不限於名稱所指的極圈與洋脊；其2026年10月19日前紀錄屬事後回溯重建。

正式聯合窗採SYNLOCK或高度警戒的成分新觸發，同區同截點去重，驗證未來168小時內、符合區域條件的M≥6事件。連續維持同一成分狀態不重複開窗；解除後再觸發可另開新窗。訊號解除或首次命中都不提前關閉原窗。SYNRELEASE不納入原正式聯合窗，僅於另列研究中評估。

| 指標 | 定義與限制 |
| --- | --- |
| 7日窗陽性預測率（PPV） | 命中的合格成熟窗數÷全部合格成熟窗數。每窗至少一筆符合條件事件即算命中；未滿168小時者不納入成熟窗分母。 |
| 事件命中覆蓋率 | 落入合格觀察窗的去重事件數÷同一口徑可評估事件數。不同觀測域及是否包含全球參考區，會影響結果。 |
| 平均首次命中領先時間 | 對已結案命中窗，計算開窗至首次符合條件事件的時間差，再取平均；不代表所有地震都能提前這麼久辨識。 |
| 靈敏度／專一度 | 須有完整、成熟且可評估的陽性與陰性樣本及TP／FP／FN／TN；不能只由開窗命中清單推算。 |
| 警戒占比τ | 合併重疊警戒區間後，計算有效警戒時間或時空負擔占比；不是把多個重疊窗直接相加。 |
| 標準差／參考區間 | 描述波動或估計不確定性，並非單次地震的發生機率。重疊窗與事件群聚會限制獨立樣本假設。 |

同一事件跨區或命中多窗，在全球事件統計中依USGS身分資訊去重，不把多窗命中數當成多起地震。若出現尚無官方共同身分證據的疑重ID，須明示待核，不擅自合併，也不把不同ID直接宣稱為已確認的獨立地震。

上述PPV與覆蓋率回答不同問題。高覆蓋率可能伴隨高警戒負擔；歷史窗PPV也不能直接當作下一次警戒的已校準發震機率。

## 回溯與前瞻，請分開閱讀

- **回溯分析**：用保存或後續修訂的歷史資料重建訊號與結果。可探索方法，但可能受目錄修訂、資料可得性與樣本內選模影響。
- **真正前瞻研究**：事先保存規則與實際發出時間，再等待後續地震結果。不得把後來重建的窗口回填成早已發布。
- **未成熟窗**：仍未完成168小時，或完整結局尚不可評估。已有部分觀測，不代表已可結案；沒有起算後目錄更不能寫成未命中。
- **缺報與排除樣本**：保留缺值與原因，不以0補齊。統計比較須列明共同觀測域與不同分母。

目前研究結果不應被描述為已證明穩定優於隨機、活動率基準或其他成熟模型。歷史探索與正式前瞻驗證須分帳，多重比較、群聚與小樣本的不確定性也須一併揭露。
